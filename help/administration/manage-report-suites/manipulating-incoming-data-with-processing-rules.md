# 처리 규칙을 사용하여 수신 데이터 조작

보고서 세트로 들어오는 데이터를 조작하여 이미 흘러가고 있는 데이터를 기반으로 해당 데이터를 추가 또는 변경하는 것은 매우 유용한 작업입니다. 이 비디오는 Adobe Analytics의 처리 규칙에 대한 개요를 제공하며 그 용도에 대해 설명합니다. 여기에는 몇 가지 팁, 예 및 경고가 포함되어 있습니다.
